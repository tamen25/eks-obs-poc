# Decisions

1. **A separate folder, not a mode of eks-logging.** The eks-logging Loki module always builds
   an S3 bucket, KMS key and IAM role; a filesystem mode would touch most of a tested stack
   for a local POC. The POC reuses only the Fluent Bit module, unchanged, so collection is
   the tested code and the rest stays small.
2. **Single binary Loki and Tempo on volumes.** No object storage was the brief. One replica
   each; losing the volume loses the data.
3. **Loki stays multi-tenant with the gateway's Basic Auth**, as in eks-logging and the target
   design (a tenant per client), so the tenant model is exercised. Tempo is single-tenant to
   keep the POC small.
4. **Traces go through an OpenTelemetry collector, not straight to Tempo.** That mirrors the
   target design's agents, and the collector adds the pod's namespace to every span, which is
   what Grafana uses to jump from a span to its logs.
5. **The demo installs the OpenTelemetry SDK at start** (pinned 1.27.0) instead of using a
   built image: no registry, nothing to `kind load` (which fails on this Docker). It needs
   internet access and adds about 20s to the pod's start.
6. **Chart versions at least two weeks old on 2026-10-29**: Tempo 3.2.0 (2026-10-14) and the
   OTel collector 0.176.0 (2026-10-13) rather than the newest. Loki, Grafana and Fluent Bit
   match eks-logging.
7. **Dashboards are generated by a Python script, not hand-written JSON.** Seven dashboards
   share variables, colours, layout and wording; one script keeps them consistent and
   reviewable. The JSON it writes is what Terraform loads.
8. **The pod-lifecycle watcher from eks-logging runs here too.** It is the only source for
   evictions through the Eviction API (no `Evicted` event is emitted) and for OOM kills with
   the container's last lines, which the evicted-pods dashboard needs.
9. **Test scenarios count lines, not just pods.** Each line carries its scenario, run and
   expected total, so "nothing was lost" is a number per scenario, both in the script's
   output and on the dashboard.
